# MERN Task Manager App

A full-stack Task Manager application built using the MERN Stack (MongoDB, Express.js, React.js, Node.js).

## Features

* Add new tasks
* View all tasks
* Update task status
* Delete tasks
* Responsive user interface
* MongoDB database integration

## Tech Stack

### Frontend

* React.js
* Axios
* React Toastify

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

## Live Demo

Frontend: https://mern-task-manager-app-ui-zeta.vercel.app/

Backend API: https://mern-task-manager-app-g5jn.onrender.com

## Installation

### Clone Repository

git clone https://github.com/DishaKeshri-23/MERN-Task-Manager-App.git

### Backend Setup

cd backend
npm install
npm start

### Frontend Setup

cd frontend
npm install
npm run dev
